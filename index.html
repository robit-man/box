Networking
      
Guest NIC is VirtIO. Relay must actually support outbound networking; a public relay is not guaranteed. Settings apply when rebooted.
    

    
Guest tools / disk

      

      Disk is 512 MiB by default; can be extended by importing a larger raw image. Save it after guest shutdown. npm installations require working guest networking.
    

  

  

    
Agent workspace
      

      The guest can mount the shared files with mkdir -p /mnt/host; mount -t 9p -o trans=virtio,version=9p2000.L host9p /mnt/host. The starter requires Node/npm and outbound HTTPS via a working relay. It grants shell execution to the selected model.
    

    
Offline export
      

      Includes the Alpine ISO, WASM, firmware and JavaScript in one large HTML file. VM disk image is not included; export the disk separately. Online npm/API requests still need an external network relay.
