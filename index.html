Initial load downloads the ISO from the separate linux-assets branch. Subsequent loads use browser IndexedDB cache. No ISO needs to be committed on your Pages branch.



Networking


Guest NIC is VirtIO. Relay must actually support outbound networking; a public relay is not guaranteed. Settings apply when rebooted.



Guest tools / disk

Provisioning starts automatically after the live Alpine root shell appears.


Installed tools include bash, sudo, curl, Git, Node and npm (when the guest can reach Alpine package mirrors). Root does not need sudo. Live ISO changes are temporary until you install to the virtual disk. Shut down before saving the disk.







Shell scripts / files




Select a local .sh file. Stage it in /root/box-scripts, review it, then run with /bin/sh or bash. The script runs inside the VM as root. 9p transfer is preferred; a slower keyboard/base64 fallback is available.



Agent workspace



The guest can mount the shared files with mkdir -p /mnt/host; mount -t 9p -o trans=virtio,version=9p2000.L host9p /mnt/host. The starter requires Node/npm and outbound HTTPS via a working relay. It grants shell execution to the selected model.



Offline export



Includes the Alpine ISO, WASM, firmware and JavaScript in one large HTML file. VM disk image is not included; export the disk separately. Online npm/API requests still need an external network relay.
